# Mackie's comic directory
## Comics, about the author, and more!
This landing page serves a hub for all of the comics I've made. Learn more about the whys and hows of comic making, from indivdual stories to multi-chapter graphic novels. A directory and blurb is provided for each comic. 


Assignment 4 - README Questions

Visual Appeal

    Which icons did you ultimately use and for what purposes?
        I added an icon for each navigation link, to make each section look more unique. I also added a previous and forward navigation icon for comic reading. I also made an icon for the dividers, but I have not added that yet. 
    Which consistent colors, values, lines, and/or shapes did you utilize and why?
        I made a much more consistent color palette, using a dark blue for text and dividers to make them stand out. A pink that isn't used many other places for comic backgrounds. A light blue for links that matches the other colors. A yellow background for the other elements that aren't comics. I also kept the radius of each border the same for consistency. 
    Which Google Fonts did you use and for what purposes?
        I used Unica One for the large text/banner fonts, which makes it stand out more. I used sono for the main text, which is monospace so it looks like a typewriter. 

Structure & Organization

    What information does your table organize, and why was a table appropriate?
        My table organizes artists I look up to, along with a blurb about what they do and a link to their work. A table works great for this since it makes all the information easy to read and relate to eachother. 
    What specific style choices helped you structure and organize your form?
        I made the form align to the left so it looks distinct from the rest of the site, but the rounded corners are the same to maintain consistency. I will eventually add an image there to make it look full. 

Design Goals

    What is the goal of your form, and how did it support your site's goals?
        The goal of my form is to provide users a way to sign up for an email newsletter. This supports my site's goal by giving users an option to interact and stay involved/updated. 
    How does the gallery support your website's goals?
        The gallery works well for showing off my artstyle in my about me page. 
    Did you use display: flex or grid to construct your gallery?
        I used display: flex since it worked the best for me. 
    What pattern did you use: uniform, alternating, or something else, and why?
        I used a uniform pattern to keep the images looking consistent and part of a whole.
